# JAOPCA: Thaumaturge

Adds [JAOPCA](https://www.curseforge.com/minecraft/mc-mods/jaopca) compatibility for [Thaumaturge](https://www.curseforge.com/minecraft/mc-mods/thaumaturge).

Note: The cluster module is automatically generated.

If customization is required, materials or labels need to be specified in the JAOPCA configuration for automatic generation.
